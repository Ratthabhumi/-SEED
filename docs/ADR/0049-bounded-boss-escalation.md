# ADR0049 — Bounded boss escalation using the existing encounter and raid models

Owner V4.3 directive authorizes a harder, perceptibly different second phase and
defensible outpost pressure. Content21 changes encounter traces intentionally;
Worldgen3, Save2 and child-law content18 remain pinned. No HP inflation,
invulnerability, extra canonical weapon owner or renderer-owned damage.

Phase two retains the existing pattern sequence, full stationary recovery,
snapshot warning geometry and lethal damage. Between attacks the boss strafes;
warning duration is80% of the phase-one duration (minimum actual .92s). Initial
aim includes up to72u of .2s linear prediction from canonical player velocity.
Target and boss origin then remain fixed through warning/commit/attack. The
fan gains four outer lanes, with the same central gap. Both simulation and
telegraph consume one exported lane list and phase-dependent duration.

On the one phase-two transition, one active specialized outpost within700u of
the player may receive a siege. Nearest distance, then stable POI identity,
selects the target. An existing raid is never replaced. Boss warning is12s (ordinary raids retain30s). Existing
spawn retry/pool bounds, visible siege units, outpost HP, repair, defeat and
repel mechanics own all consequences. No immediate or remote invisible damage.
The existing raid event optionally identifies a boss source for EN/TH messaging.

Incoming-hit tint remains, but continuous hits must not replace a painted
windup/release/recovery pose or continuously rotate its body. Authored idle hit
cell and the opt-in historical art baseline remain available. This fixes
readability with existing source frames; it does not complete authored animation.

Before/after Natural36 retains all reached, unreached, defeat and replay results.
There is no target win percentage. Physical frame acceptance, human challenge,
fairness and aesthetic approval remain separate from automated verification.
