# ADR0059 — Owned weapons and full run checkpoints

Status: Content29 corrective candidate; final acceptance follows the PR44 receipt. Historical Content28 decision and failures below are retained; the corrective section supersedes the single-starter default.

## Context
Origin pairs conflated affinities and ownership. A single primary rig could not represent independently firing visible weapons. Save3 persisted profiles, not runs. Draft formulas obscured choices.

## Decision
Content28 owns up to3 unique-family instances: stable ID, player owner, slot, rig and aura clock. Existing family stage/cooldown stores and shared bounded pools stay authoritative; no duplicate damage loop. Field uses actual mines and its deployment clock; Defense uses orbit/guardians. Unique families make those clocks independent. Primary is slot0; secondary releases never restart body attacks/facing. Aim and fire share emitter-local targeting and actual authored muzzle geometry.

Default runs start one Origin signature. Stone acquisition Tech uses existing foundations and chooseDraft validation; all4 Origins can acquire additional weapons without Archive grind. The existing optional Archive energy start consumes a real slot. No family duplicates, fourth slot or replacement inventory.

Offer protection uses the existing sampled candidates and draw budget. A legal acquisition and available early tactic are retained with sampled relative order. Acquisition metadata uses existing Origin score modifiers. No forced player pick or free grant.

World2 carries weapon IDs/families, resets stages/clocks. Explicit Origin choice changes signature: reorder when already owned; otherwise replace old slot0 at3/3, as disclosed in the intro. Child laws18 and affinity Legacy rules stay pinned.

Save4 adds an optional complete canonical checkpoint with5 RNG streams, bounded/finite shape validation, content/worldgen identity and checksum. Resume preserves unsettled attempt ID and reward-presentation history; it never restores a loadout into a new run. Save1–3 profiles retain Insight/collection. Corrupt/incompatible checkpoints fail safe; this is corruption protection, not anti-cheat.

Draft uses legitimate atlas crops, short plain copy, canonical outcomes and static diagrams capped at12 marks using shared volley angles. Technical information remains in one focus-trapped Details surface. Large text uses one workspace scroll, no card scrollbars.

## Evidence and limit
Multi-target regression exposed aim/fire selecting different enemies; both now use the same emitter-local query. Independent aura clocks and orbit hit clocks prevent mutual suppression; orbit advances once perstep. Save/future-input/World2 replay and actual three-build damage regressions pass their focused checks. Old isolated fixtures explicitly acquire their tested secondary through eligible Tech. Historical Natural36 controllers remain unchanged.

ClassC first-pick/domain divergence still fails unchanged thresholds. Shared single-signature openings and unrestricted acquisitions change Origin distributions. Bounded offer experiments stopped; owner must review differentiation versus freedom before changing design or acceptance contract. Mechanical execution is not human fun acceptance.
