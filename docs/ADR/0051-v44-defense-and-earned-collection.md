# ADR0051 — bounded defense and earned collection

Owner V4.4 authorizes this design without incremental approval. Prior recalled fun1/5 remains the baseline; engineering and human acceptance remain separate.

Only bases near the encounter and player qualify for boss assault. A12s attempt window and24s reengagement cooldown bound travel, with expiry applied only at safe phases. No nearby base means normal combat, not an unlimited chase. Existing warned geometry and base HP/loss/repair remain authoritative. This intentionally changes replay Content22→23; Worldgen3 and child-law18 remain pinned.

Five earned cosmetic identities: Bronze dawn emblem; actual defended-raid ward emblem; two different Origins reaching Bronze unlock prism trail; actual boss victory unlocks star ornament; Ascension unlocks chronicle ornament. These are first-three-run opportunities, not guaranteed rewards by run number. No random rewards, currency, paid system or combat bonuses. Repeated observations cannot duplicate an identity. Existing Insight settlement/purchases are untouched.

Collection is a small validated save field, schema3 with explicit schemas1/2 migration. Existing licensed artwork and bounded original geometric ornament/trail presentation are used; no claim of new painted anatomy. Equip/unequip and preview belong on title, pause and result surfaces. Actual runtime state drives rewards, not QA telemetry counters.

Historical policy/results stay intact. A separately named defender-aware controller intercepts the actual boss or threatened base and measures range/travel/phase/defense outcomes. Neither synthetic outcome establishes fun. No large weapon architecture, inventory engine, speculative renderer rewrite or external research.
