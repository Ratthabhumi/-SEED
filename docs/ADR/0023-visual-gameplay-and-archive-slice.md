# ADR0023 — Living frontier and bounded attempt Archive

User-authorized visual/gameplay experiment from781687a. No forced first loss or attempt-dependent threat multiplier. Attempt is independent of child World; Archive persists across attempts, inherited Legacy only across surviving child transitions.

Schema2 migrates schema1 under the existing storage key, preserving settings, legacy archive identifiers, best and history. New currency starts at zero; old runs do not receive retrospective rewards. Three one-time purchases:3 Insight for root-start+15HP;5 for an optional extra energy core when Origin lacks energy;4 for one extra Stone-age redraw. No repeated power purchases or grind gate. Effects reset on Ascension with the other root equipment; Origin threat/abilities unchanged.

Terminal payout is1 + min(5,full run minutes) + min(5,highest age index) +2 if a boss was actually defeated, maximum13. QA target completion is observation completion, not an attempt reward. Production test staging (?e2e) earns zero currency. Each freshly created attempt reserves a monotonically increasing persisted serial; terminal settlement accepts only an issued serial newer than lastSettled. All repeated/stale settlements fail closed, including after reload. Single active attempt is the supported local game model; out-of-order tab settlements are not a multiplayer economy. Quota failures are visible and never described as persisted progress.

World collision/pathfinding is unchanged. Original vector/code-native decorative art is reviewed as a working vertical slice, not full asset production. Never introduce implied collision, copy commercial assets, or spend canonical RNG on cosmetic layout. Existing budgets remain acceptance targets, not certified60FPS.

Content11 adds Conduction and Relay acquisition nodes. Conduction chains once per energy projectile/aura/beam strike, max two unique additional targets within120 per hop at50% previous damage. Area victims are excluded from extra hops; stable pool order breaks ties, no RNG or recursion. Relay activates at most three operational specialized bases every2s, range180, damage8×build multiplier. Acquiring both unique tags unlocks Resonant Frontier (relay chaining); foundation domain tags cannot do so. Quality does not scale boolean capabilities. New flags and cooldown are hashed, reset on child worlds. Victory is voluntary after an actual boss kill via Pause → Finish attempt; living completion emits run_completed, retains health and ends QA as victory-finished. Defeat/victory use the same idempotent ledger settlement.

Decorative Verdant grass and worn ground use a dedicated cosmetic hash namespace; no collision, displacement, enemies, POI layout or travel-time change. Physical obstacle terrain remains deferred until canonical navigation/reachability exists. Site preview reads current biome bonuses, direct distance, hostile count and exact capacity cost through canonical validation. Reduced Effects hides ornamental bursts/tween sprites/shake, keeping hostile telegraphs and brief functional energy links. No new audio samples/dependencies; existing licensed/generated sound palette retained.

Audio uses original synthesized tones with eight concurrent voices maximum, per-frequency/type50ms repeat throttle,4ms gain attack and per-voice gain≤.12 (sum≤.96). Functional energy attacks emit one cue per event batch. Voice cleanup disconnects nodes on completion; no external sound assets or provider.

Chronicle provides an explicit Return to Archive route beside Play Again. victory-finished is a recognized QA terminal reason with its own identity; automated watcher finalization is report processing, not settlement or a human fun verdict. At desktop width≥1100 pause uses three columns with optional world traits in native details; smaller/200% layouts retain safe vertical scrolling.

Site hostile preview uses the exact canonical spatial query, including enemy hit radius and cached broadphase semantics. It may increment diagnostics queryCount, never state hash or RNG; center-only counting would under-report threats at the clear-radius boundary. Border overlap has a regression.
