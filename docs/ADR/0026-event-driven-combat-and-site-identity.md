# ADR0026 — event-driven Energy feedback and canonical site identity

The production renderer lacked a beam release observation and specialization
input for ground architecture. Add immutable `beam_fired`, `energy_impact` and
`knowledge_collected` observations to the simulation event contract. They expose
resolved outcomes without altering gameplay, state ownership or RNG. Capture
beam aim before death/split can recycle its target slot; keep the legacy excluded
beamFlash presentation field compatible.

The legacy compass fallback independently scanned undiscovered POIs, violating
the requested known-coordinate boundary. Remove that scan and localize generic
exploration/Signal guidance; retain bearings from discovered frontier focus and
explicit canonical Stronghold revelation. No discovery radius/worldgen change.

Presentation uses fixed pools and simulation-time lifetimes. Reuse the existing
licensed impact texture, original code-native vector site artwork, typed theme
and existing repair UI. No new dependency, canonical timer, balance change,
world geometry or persisted field: worldgen2/content12/save2 remain valid.

Explicitly defer expansion to three more polished weapon signatures, authored
hero combat/death poses, canonical multi-pattern boss and environment production
until the first native-scale slice provides a credible quality target. This
checkpoint makes the concrete review playable; automation does not authorize
production art, hardware60FPS or a human fun verdict.
