# Civilization playability: reviewable checkpoints

Date: 2026-10-11. Status: implemented; local regressions verified; exact-SHA CI and fresh human revalidation gate delivery.

The human run on content 8 exposed narrow overflowing decision surfaces,
untranslated quality labels, an exhausted reroll pool, and silent logistics
rejection. The earlier optional-picker repair remains valid; it did not deliver
the requested extensible technology web. These are separate acceptance layers.

First repair decision clarity: canonical upgrade/reroll validation, responsive
surfaces, truthful effective-effect previews, and explicit logistics reallocation.
Claims remain free. Reallocation returns only the cost already committed to a
specialization, removes its benefits/tier, never heals or grants knowledge, and
cannot farm the first-Signal exemption. Age gates remain unchanged.

Geography must have actual deterministic tradeoffs, exposed to players, with
cached chunk lookup and no geometry/save-schema change. Balance/content changes
require CONTENT_VERSION advancement and renewed cohort validation.

The technology-web checkpoint must precede any claim of full completion: one
root, four domain foundations, legal cross-domain joins, bounded deterministic
expansion, one eligibility rule, and stable radial presentation independent of
simulation. Preserve authored tag semantics and six age milestones. No runtime
LLM, new dependency, enemy director expansion, or infinite-content claim.

Do not call an interrupted or incomplete human run a fun pass. Keep raw human
reports private and durable; browser output is isolated in test-results/browser.
Validation distinguishes source/unit/browser/cohort/CI from a fresh human run.

Four structural foundations are opened at run start with zero effects; they are
not draft rewards. Eight starting applications retain active weapon-family
compatibility, so origins differ through actual usable packages. Universal
authored modules keep every domain accessible. Age milestones are automatic,
not draftable rewards. The legacy content-8 test fixture retains its old rules.

Web depth is a bounded generation level, not shortest-path DAG distance.
Coordinates depend only on domain, generation level and stable insertion slot;
lazy expansion cannot move existing nodes. This intentional content change
invalidates content-8 choice traces while preserving world geometry/save schema.

Watchdog evidence: an exact git archive of d3814a6, unmodified Class B, shared
unchanged dependencies and one worker, took 192.93s for the test (230.35s total)
and failed its existing 60s watchdog plus onTaskUpdate RPC. Its log is retained
privately at scratch/baseline-performance.log. Windows watchdogs increase to
600s and workers to one; Linux retains original 60/90/120s caps. Statistical
thresholds, policies and sample counts remain unchanged. Watchdogs are not a
game frame-time measurement or performance-budget waiver.

Natural factorial audit also yields the JavaScript event loop between complete
traces, allowing worker RPC to settle. Every trace remains synchronous with
identical canonical step count/inputs; no gameplay timing depends on wall time.

Reallocation of a garrisoned base returns at most one living reserve ally under
the resulting mobile cap and preserves its HP; it never creates/heals/revives
an ally. The current reserve model stores no per-base ally identity.

Ascension reset assertion now expects the root plus exactly four zero-effect
structural markers, retaining the reset of all purchased applications. This is
an intentional content-9 contract change, not a weakened reset assertion.

Generated frontier joins require two actually acquired effect-bearing
technologies from different domains. Free domain markers do not qualify. The
supporting choice must be at/below the parent generation level, so both edges
progress outward. With one invested domain, only its continuation is generated.
The six authored mixed packages are separately template-based and require the
two open domain markers plus their age gate, not two purchased technologies.

Snapshot territory fields added by this work append to the old positional prefix; browser readers retain their existing disabled/heldSince/repair indices. Radial connections use straight segments rather than horizontal DAG curves. Current view ignores fallback rewards without graph coordinates and retains the most recent real node; browser assertions verify actual nodes intersect the viewport, not just the outer panel.

Panzoom applies an asynchronous initial pan after construction. Its startX/startY/startScale are now derived from the same current-frame calculation as explicit focus; a later reset cannot erase the first view. Terminal-reward and mobile regressions assert that real graph nodes intersect the viewport.
