# Animation production contract — Content15 reference

This extends the existing dark painted fantasy/science-fiction direction. It does
not change Worldgen3 / Content15 / Save2, simulation geometry, damage or input.

## Reproducible production path

1. Author original weapon-neutral key poses or PNG sequences in Krita; preserve
   editable layered project files when available. Imagegen can supply key-pose
   drafts, but must not be treated as authored in-between motion or human approval.
2. Export transparent PNGs with explicit facing/action/frame names. The current
   reference source is a regular9×4 grid: Hunters Stone front/back, Space front/back.
3. Run `python scripts/pack-animation-reference.py assets/original/content15-animation/hunters-reference-v1.png assets/seed/content15-animation src/game/assets`.
   For separate editable frames, run `python scripts/export-reference-sequences.py assets/original/content15-animation/hunters-reference-v1.png scratch/authoring-reference`.
   Edit those distinct PNG poses in Krita, then pass `scratch/authoring-reference/source.json`
   to the same packer. The reference import currently requires36 poses in the
   documented9×4 order; changing the frame/state contract needs deliberate metadata/
   playback integration. Individual source PNG SHA256 values are exported, too.
4. The importer rejects missing alpha/empty cells/identical pose pixels, locks one
   scale per row from its idle body, fits within128px cells, and records bounds,
   ground/collision anchors, per-pose sockets, source SHA and authored-frame hashes.
   It exports a PNG atlas, animation metadata and Phaser-compatible JSON atlas.
   No poses or intermediate frames are synthesized by the packer.
5. Inspect source/contact sheet and native gameplay-camera captures, including
   weapon alignment, facing flips, pause, restart, World2 and graphics modes.
   Add frames only after consistent anatomy, spacing and silhouette review.

Tools: existing Pillow offline utility and Phaser4.2.1 runtime, project MIT assets.
No new dependency or separate animation engine. Krita is an optional external
authoring tool; no Krita project has been fabricated for this generated source.

## Spatial, event and lifecycle invariants

- Every atlas cell128×128; source feet aligned to local[64,116]. Sprite origin
  remains[.5,.65], collision point[64,83.2] under the existing body contract.
  Thus visual feet are below the canonical player position; no hitbox is moved.
- Upright body rotation0. Front/back selected from actual displacement; horizontal
  flip mirrors the socket offset. Main-body scale112 world units remains unchanged.
- A single separately mounted primary weapon uses the active frame's hand socket.
  No weapons are baked into any of the36 reference poses. Autonomous Field/Defense
  emissions and mine detonations do not manufacture a handheld attack pose.
- Actual weapon/beam, hurt and Origin ability SimEvents drive presentation actions;
  dash/death use real canonical state. Repeated event revision restarts its clip.
  Walk follows movement. Simulation time freezes frame progression on pause;
  rewound time/age/facing/action changes reset the adapter clock.
- No action is generated by animation playback. Hit/VFX geometry and weapon-stage
  rules stay canonical. Reference-image hand/muzzle appeal is still a human gate.
- Renderer-owned texture atlas persists in Phaser's TextureManager. Scene shutdown
  destroys images and timers; new ActorRenderer/feedback pools reset playback.
  World2 resets time/facing history. Worker and WebGL/Canvas fallbacks stay supported.
- Reduced Effects suppresses optional VFX, not the action identity. High Contrast
  retains original danger geometry; English/Thai interface text remains normal UI
  typography, Thai line-height≥1.7, never replaced by numeric bitmap glyphs.

## Delivered versus incomplete motion

| State | Hunters Stone/Space front/back | Other Origins / Ages |
|---|---|---|
| Idle | One authored neutral key pose | Existing static neutral costume |
| Walk | Two distinct gait poses,125ms/frame | Existing procedural bob |
| Attack/recover | Reach/recoil two poses,80ms/frame; event revision | Existing procedural equipment response |
| Hurt/dash/Origin ability/death | One distinct key pose per state | Existing procedural/static response |
| Full smooth authored clips | **Pending**, especially idle/hurt/dash/ability/death in-betweens | **Pending** |

Single poses are not advertised as finished animation clips.36 unique source cells
and sparse walk/attack playback constitute a reference integration, not a full
library or art approval. Boss/enemy/squad/Guardian/outpost/biome sets retain existing
assets; their missing six-era motion kits remain explicit in the quality audit.

## Memory and scaling budget

| Runtime sheet | Pixels | Frames | RGBA allocation estimate |
|---|---|---|---|
| Neutral costumes |768×1024|48|3MiB|
| Reference key poses |1152×512|36|2.25MiB|
| Four old squad/pose sheets |4×512×512|4×16|4MiB|
| Hostile vector glyph cache |512×512|at most64|1MiB|
| Numeric prototype (opt-in) |130×20|13|10,400bytes|

Estimates exclude driver overhead/mips and other world/combat atlases. Reference
sheet is loaded once per game and reused across actions/worlds; no sheet per event.
Alpha bounds and actual occupied rectangles are exported for packing review.
Do not multiply36 frames by every Origin/Age blindly. Next batch requires measured
resident memory/render cost, shared scale/socket templates and human source review.

## Authoritative visual guide

Painted materials, warm Stone leather/fur transitioning to weathered Space ceramic/
metal, green Hunters cloth; preserve teal Engineers, violet Resonant and red
Sentinels identities. Characters must stand above quieter low-frequency terrain.
Hero112, boss240; family-specific enemy hierarchy remains. Avoid bright terrain
motifs that mimic pickups or threats. Primary weapons have one clear family
silhouette and a directional muzzle; hostile shots keep barbed arrowheads and a
dark outline, allies retain their original painted identities. Warning lanes show
actual danger; bosses/elite tells outrank ordinary VFX. UI uses existing material/
contrast tokens, with Reduced Effects and High Contrast checked independently.

Technical acceptance checks frame distinctness, alpha, bounds, socket export,
timing, actual event correspondence, pool/texture lifecycle and native captures.
Artist acceptance checks anatomy, pose appeal, motion spacing, continuity and
readability at112px. Human gameplay acceptance checks comprehension/fun/replay.
These are separate gates; automated assertions cannot approve the latter two.
