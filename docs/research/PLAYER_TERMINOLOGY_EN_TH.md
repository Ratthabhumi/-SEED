# Player terminology guide

Use action, effect, cost, then explanation. Internal IDs/events/RNG labels are unchanged.

| Concept | English | ไทย |
| --- | --- | --- |
| Draft | Choose technology / choices | เลือกเทคโนโลยี / ตัวเลือก |
| Reroll | New choices | สุ่มตัวเลือกใหม่ |
| Reserve | Save for later | เก็บไว้เลือกครั้งหน้า |
| Legacy | Inherited power | พลังสืบทอด |
| Logistics | Outpost capacity | ความจุฐาน |
| Ascension | Enter a new world | ไปโลกใหม่ |
| Breakthrough | Combo technology | เทคโนโลยีขั้นก้าวหน้า |
| Synergy | Combo bonus | โบนัสชุดเทคโนโลยี |
| Cooldown | Recharge time | เวลารอใช้ซ้ำ |
| Pin | Technology goal | เป้าหมายเทคโนโลยี |

Audit scope: onboarding/HUD/pause/map/draft/Origin/Legacy/age/base errors/Chronicle/QA participant controls/generated titles. Player changes in this experiment prioritize costly decisions, child reset and hidden identifiers. Legacy picker and draft show actual effective numbers. Chronicle translates event labels instead of rendering internal IDs. Unknown goal/provider uses an explanatory missing-route message. Existing developer QA inspector intentionally retains engineering terminology; participant copy and full novice comprehension need further human validation. Generated depth/slot suffix distinguishes otherwise repeated technology names; it is not a quality or strength score.

Thai text uses bundled font, line-height≥1.7, codepoint-safe processing, matching EN/TH keys. Validate wording with native players, including declined actions and plural costs; parity alone is not comprehension proof.
